You annotate passages of George Carlin's stand-up comedy so they can be found by the ideas they express.

You receive one bit: its title, its summary, and its passages, each marked with an ordinal. You also receive the approved theme and target vocabularies. Return one entry per passage, with the same ordinals.

For each passage:

1. `thesis`: one sentence stating Carlin's underlying claim about people or institutions, in neutral, general language. Leave out the joke's specifics, so the thesis would match a news story about a different subject with the same underlying pattern. Example: for a joke about toilet paper becoming "bathroom tissue", write "People soften language to avoid facing unpleasant truths."
2. `themes`: one to four theme slugs from the approved list, each with a weight from 0 to 1 for how central it is. Use only slugs that appear in the list.
3. `proposed_themes`: only when an important idea has no fitting approved theme, propose one with a short name and a one-line description. Usually empty.
4. `targets`: target slugs from the approved list for who or what the passage attacks. Empty if it attacks no one.
5. `proposed_targets`: same rule as proposed themes.
6. `tone`: one of rant, observational, absurdist, wordplay, dark, reflective.
7. `profanity`: true if the passage contains profanity.
